# Data dictionary

All timestamps are `timestamptz` in UTC. Coordinates are WGS84 (EPSG:4326). The schema is
created by `alembic/versions/0001_initial_schema.py`.

## Provenance

### `data_sources`
| column | type | notes |
|---|---|---|
| source_id | serial PK | |
| name | text unique | e.g. `noaa_marinecadastre_ais_2023`, `nga_world_port_index_pub150`, `synthetic_scenario` |
| publisher, url, license, notes | text | |
| access_date, coverage_start, coverage_end | date | |
| is_synthetic | bool | true for every generated dataset |

### `ingestion_runs`
One row per (file SHA-256, bbox). `status` in `running/completed/failed`;
`last_chunk_done` is the resume checkpoint; `rows_raw, rows_in_bbox, rows_accepted,
rows_rejected, rows_duplicate, rows_inserted`; `quality_report` jsonb holds the full
data-quality report (missingness by field, flags, reject reasons, coverage) and the
resumable accumulator state. Unique `(file_sha256, bbox_key)`.

## Observations

### `vessels`
| column | type | notes |
|---|---|---|
| mmsi | text PK | `CHECK (mmsi ~ '^[0-9]{9}$')`; always text |
| vessel_name, imo, call_sign | text | latest non-null value seen; IMO without `IMO` prefix |
| vessel_type, cargo | int | AIS codes as published |
| length_m, width_m, draft_m | real | 0 -> NULL |
| transceiver_class | text | A / B |
| first_seen, last_seen | timestamptz | widened on every load |
| source_id | FK data_sources | |
| is_synthetic | bool | |

### `ais_positions`
| column | type | notes |
|---|---|---|
| position_id | bigserial PK | referenced by evidence |
| mmsi | FK vessels | |
| base_datetime | timestamptz | |
| lat, lon | float8 | range CHECKs |
| sog | real | knots; NULL if unavailable/invalid; CHECK 0-102.2 |
| cog, heading | real | degrees [0, 360); NULL if unavailable |
| nav_status | int | AIS navigational status (self-reported) |
| draft_m | real | |
| quality_flags | int | bitmask, see below |
| source_id, run_id | FKs | provenance per row |
| geog | geography(Point,4326) | generated from lon/lat; GIST index |

Unique `(mmsi, base_datetime, lat, lon)` makes loads idempotent. Indexes:
`(mmsi, base_datetime)`, `(base_datetime)`, GIST `(geog)`.

`quality_flags` bits: 1 SOG_UNAVAILABLE, 2 SOG_INVALID, 4 COG_UNAVAILABLE, 8 COG_INVALID,
16 HEADING_UNAVAILABLE, 32 HEADING_INVALID, 64 MMSI_SUSPECT, 128 CONFLICTING_TIMESTAMP.

### `ports`
WPI number (unique), name, alternate name, UN/LOCODE, country, region, harbour size/type,
lat/lon, generated `geog` with GIST index, source_id, is_synthetic.

## Derived

### `voyages` (trajectory segments)
`mmsi, segment_index, start_time, end_time, n_obs, distance_km` (sum of in-segment
geodesic steps), `start_port_id / end_port_id` (WPI port within the proximity radius of
the first/last fix, else NULL), `gap_before_s`, `gap_before_context`
(`near_study_area_edge / in_port / mid_region_unexplained`), `method`
(`gap_jump_segmentation_v1`), `track` LineString (simplified, 0.00005 deg). Unique
`(mmsi, start_time, method)`.

### `port_proximity_events`
`mmsi, port_id, start_time, end_time, n_obs, min_distance_m, radius_m, position_ids
bigint[]` (every supporting fix). Unique `(mmsi, port_id, start_time, radius_m)`.
Geographic proximity only.

### `model_runs`
`model_name, model_version` (unique pair), `params, feature_list, library_versions,
metrics` jsonb, train/eval windows, `n_train, n_eval, data_hash, artifact_path,
is_synthetic`.

### `anomaly_events`
`run_key` (rules: hash of rule config; model: model name + version), `detector`
(`rule / isolation_forest`), `anomaly_type`, `mmsi, event_time, end_time, lat, lon`,
`score` (model only), `rule_flags` jsonb (measured values + thresholds), `features` jsonb
(model contributors, track id, split), `explanation`, `quality_notes`,
`supporting_position_ids bigint[]`, `model_run_id`. Unique
`(run_key, detector, anomaly_type, mmsi, event_time)`.

## Investigations

### `investigation_cases`
`title, description, status` (CHECK in `New, Under review, Explained, Insufficient
evidence, Closed`), `created_by, created_at, updated_at`.

### `case_evidence`
`evidence_type` in `anomaly / position / proximity / note` with a CHECK that the matching
FK (or note text) is present; `provenance` jsonb captured when attached (source dataset,
ingestion file + hash, detector, run key, model version); unique per case per anomaly and
per position.

### `case_status_history`
Every status change with old/new status, who, why and when.

## File outputs (`data/processed/`, regenerated by the pipeline)

| file | content |
|---|---|
| `steps.parquet` | per-fix step metrics: dt_s, step_m, implied_kn, bearing, course/speed change, segment_id, is_gap_start, is_jump, gap_context, nearest_port_id, port_dist_m, density_log10 |
| `track_features.parquet` | one row per vessel-day: identifiers, vessel_type_group, the 28 features |
| `track_scores.parquet` | Isolation Forest score + split per real track |
| `network.json` | NetworkX node-link graph with edge evidence |
| `network_nodes.parquet` | degree, degree centrality, betweenness, community |
| `port_transitions.parquet` | port A -> port B counts and distinct vessels |

## Track features (vessel-day)

| feature | definition |
|---|---|
| mean_sog, median_sog, max_sog, std_sog, p95_sog | reported SOG statistics (kn) |
| mean_abs_sog_change | mean \|ΔSOG\| between consecutive fixes |
| max_abs_accel | max \|ΔSOG\| per minute (intervals ≥ 30 s) |
| mean_course_change, p95_course_change | \|ΔCOG\| while moving (≥ 2 kn), intervals ≤ 5 min |
| max_implied_kn | max implied speed (intervals ≥ 30 s) |
| p95_speed_discrepancy | p95 of \|implied − reported\| for 30-600 s intervals, steps > 50 m |
| n_obs, duration_h | fixes and first-to-last span |
| route_length_km | sum of in-segment steps (gaps and jumps excluded) |
| displacement_km, route_efficiency | first-to-last distance; displacement / route length (NaN if route < 0.5 km) |
| heading_variation | circular std of COG while moving |
| low_speed_frac, longest_low_speed_h | share of fixes < 0.5 kn; longest continuous run |
| min_port_dist_km, mean_port_dist_km, frac_near_port | distance to nearest WPI point; share within 2.5 km |
| mean_density_log10 | log10 fixes in the ~1 km cell (all real vessels, whole week) |
| obs_per_hour, n_gaps, max_gap_h, coverage_continuity, n_jumps | reporting regularity |
